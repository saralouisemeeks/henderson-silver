# Henderson Family Silver Plate Collection

Sales page for 33 lots of family silver plate.

- `index.html` - the page: lots, descriptions, prices, contact.
- `images/` - lot photos, named by lot number (for example `025-01.jpg` is lot 025's headline photo).

Live at https://saralouisemeeks.github.io/henderson-silver/ once GitHub Pages is turned on.
